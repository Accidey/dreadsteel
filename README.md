# Dreadsteel

**Dreadsteel** is an unofficial port of the original *Dreadsteel* mod, created by **Mindoth** for Minecraft 1.20.1 (Forge), ported to **Minecraft 1.21.1 (NeoForge)** by **Accidey**.

## Overview

Dreadsteel adds a complete end-game equipment set forged from the eponymous alloy: a four-piece armor set, a scythe, and a shield. All items are unbreakable, enchantable, and can be recolored with cosmetic kits. Wearing the full armor set grants immunity to fire, cactus (spikes), and lightning damage.

## Features

- **Dreadsteel Armor Set** — Helmet, Chestplate, Leggings, and Boots. The full set grants immunity to fire, cactus, and lightning damage.
- **Dreadsteel Scythe** — While attacking, summons a magical spinning blade that pierces all enemies and armor on hit.
- **Dreadsteel Shield** — While blocking, incinerates incoming projectiles and ignites melee attackers.
- **Cosmetic Kits** — Recolor equipment among Default, White, Black, and Bronze at an anvil.
- **Configurable Stats** — Armor values, toughness, knockback resistance, scythe damage and attack speed are configurable, with hot-reload support.
- **Unbreakable & Enchantable** — All Dreadsteel items have infinite durability.
